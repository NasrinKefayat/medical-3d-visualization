
Medical 3D Visualization
========================

Overview
--------

This project converts medical image segmentation masks
into interactive 3D surface meshes.

Workflow
--------

1. Medical image loading
2. Geometric alignment
3. Mesh reconstruction
4. Interactive visualization
5. Quantitative mesh analysis

Technologies
------------

Python, NiBabel, NumPy, scikit-image,
Trimesh, Plotly, and 3D Slicer.

Dataset
-------

HCUCH CT Dataset.

DOI: https://doi.org/10.1038/s41597-026-06597-6

Limitations
-----------

This project demonstrates geometric reconstruction
and visualization.

It does not include physical 3D printing,
haptic interaction, or mechanical simulation.
